# 지니어스 게임 v5 · 회전형 게임 선택 화면

현재 GitHub 소스(기준 트리 d93c0e2a5d4c1aca53196820388526f4ab7c5b2f)에서 수정한 전체 소스입니다. 제공한 게임 URL 10개와 기존 이미지가 포함됩니다. GitHub에 직접 업로드하거나 운영 사이트를 배포하지 않았습니다.

## 적용

1. 기존 서비스의 교사 메뉴 → 백업·복구에서 JSON을 내려받습니다.
2. ZIP을 풀고 내용물 전체를 기존 GitHub 저장소 루트에 덮어씁니다.
3. 커밋 후 Vercel 재배포가 끝나면 새로고침합니다.

Vercel 설정: Vite / Build npm run build / Output dist. 별도 환경변수는 없습니다.
로컬 실행: npm ci → npm run dev. 테스트: npm test.

## 변경 사항

- 시즌 생성 버튼을 우측 상단 저장 표시 왼쪽으로 이동.
- 체험하기·메인 백업 복구·영문 하단 문구 제거. 백업·복구는 시즌 생성 전에도 교사 메뉴에서 접근 가능.
- 가운데 게임 카드가 가장 크고 선명하고, 양옆 카드는 작고 흐린 회전형 배치.
- 휠, 좌우 버튼, 마우스/터치 가로 드래그, 양옆 카드 선택, 하단 바로선택 점으로 게임 이동. 목록에 키보드 초점을 두면 방향키 사용 가능. 자동 회전 없음.
- 게임 선택 화면은 화면 높이에 맞춰 한 화면에 배치. 최종 순위는 세로 스크롤 유지.
- 시즌 미생성 게임 상태는 '대기'.
- 참가 학생 입력란과 학생 선택 영역을 세로로 확장.
- 학생은 이름만 입력. 기존 백업 호환을 위해 내부 순서 식별값은 자동 유지되지만 화면에 번호 입력은 없음.
- 학생 이름 복사 버튼은 팝업 없이 즉시 이름만 복사. 호버·키보드 초점 시 붙여넣기 안내 툴팁 제공.
- 이용권 영역·구매·기록은 유지하고 교사용 이용권 설정 제거. 상품은 catalog.ts의 고정 product에서 추후 등록. 이전 이용권 거래 내역은 보존.
- 회차별 보상 설정을 게임 소개 공간으로 변경. 소개는 추후 catalog.ts의 introduction에 입력. 지금은 준비 중 표시.
- 결과 입력의 순위·우승·수동조정 항목 제거. 학생 이름·참가 여부·가넷 지급으로 단순화하고 데스크톱에서 2단 배치. 좁은 화면에서는 1단.
- 기존 미지급 결과는 개인별 총액을 유지하며 직접 지급으로 변환. 이미 지급한 결과와 장부는 유지.
- 게임 관리에서 마우스 드래그로 순서 변경. 키보드용 위/아래 이동 버튼도 유지.
- 교사 메뉴의 세부 화면에 돌아가기 추가. 게임 관리에서 소개로 들어간 뒤에는 게임 관리로 복귀.
- 학생 장부의 가넷 −/+ 버튼은 숫자 입력값만 1씩 증감. 입력값을 확인한 후 '가넷 반영'을 누르면 저장되고 지급/차감 완료 팝업 표시.
- 가넷 장부 수동 지급은 보유·누적·최종 순위에 반영. 시작 지급은 누적 획득에서 제외.
- 초기화는 경고 팝업에서 확인한 후 실행. 명단·게임 목록은 유지하고 결과·장부·이용권 거래 초기화, 시작 가넷으로 복원. 취소 시 변경하지 않음.

## 검증과 확인할 사항

TypeScript 타입 검사, 계산·저장·장부·이용권·직접 지급 변환·정렬·백업·명단 테스트 23개 및 Vite 프로덕션 빌드를 통과했습니다. 로컬 HTTP 응답은 정상입니다.

현재 브라우저/컴퓨터 점검 도구가 실행되지 않아 실제 화면의 크기·겹침·마우스 드래그와 클립보드, 팝업을 통한 전체 동작의 시각 검증은 완료하지 못했습니다. 배포 후 다음을 확인하세요.

- 가운데 카드와 하단 메뉴가 한 화면에 들어오는지
- 좌우 버튼/휠/가로 드래그로 선택 게임이 바뀌는지
- 이름 등록, 즉시 복사, 개별 게임에 붙여넣기가 되는지
- 학생 장부에서 −/+ 입력값과 반영 후 실제 보유량이 일치하는지
- 결과 지급 2단 배치와 재접속 후 기록 유지
- 게임 드래그 정렬 및 돌아가기
- 초기화 팝업에서 취소하면 보존되고 확인하면 시작 상태로 돌아가는지

기록 저장은 HTTPS 또는 localhost 환경과 최신 Chrome/Edge의 Web Locks가 필요합니다. 폰트는 기존 웹폰트를 유지하며 CDN 접근이 제한되면 시스템 폰트로 대체됩니다.
