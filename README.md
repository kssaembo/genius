# 지니어스 시즌

React · TypeScript · Vite로 만든 교사 PC용 시즌 운영 서비스입니다. 서버·계정·DB 없이 현재 브라우저의 LocalStorage에 저장합니다.

## 실행

```sh
npm install
npm run dev
npm test
npm run build
```

실제 사용은 HTTPS 호스팅 또는 localhost에서 실행하세요. 파일을 더블 클릭하는 file:// 방식은 지원하지 않습니다. 최신 Chrome·Edge의 Web Locks로 탭 간 동시 수정 충돌을 막습니다.

## 운영

시즌 생성 → 학생 일괄 등록 → 게임 선택 → 게임 관리에서 순서·보상 설정 → 회차 시작 → 외부 게임 진행 → 결과 입력 → 지급안 확인 → 가넷 지급 및 결과 공개 → 다음 회차 → 교사 메뉴에서 최종 공개 → 백업.

한 회차에 경기를 추가하면 경기마다 참가 보상을 포함한 규칙을 적용하고 합산합니다. 결석자는 경기별 참가 체크를 해제하세요. 지급은 원자적인 전체 상태 저장에 성공한 뒤 연출합니다. 재생은 장부를 변경하지 않습니다. 지급 취소는 원 거래를 남기고 반대 거래를 추가하며 잔액 부족을 차단합니다.

순위는 게임 보상과 명시적인 획득 보너스만 합산합니다. 시작 가넷·추가 구입·환불·잔액 정정은 순위에 영향을 주지 않습니다. 공동 순위는 1·2·2·4 방식입니다. 학생 상세에서 시작 가넷 예외는 '잔액만 조정'으로 기록하세요.

## 제공이 필요한 고정 정보

`src/catalog.ts`의 10개 게임 각각에 다음 값을 입력합니다. 화면에서 URL·가격을 수정하는 기능은 없습니다.

- 실제 고정 URL (`url`)
- 실제 썸네일 (`thumbnail`, 자체 제공 이미지를 public/에 저장 후 경로 입력)
- 이용권명·설명·정수 가격·판매 여부 (`product`)

현재 URL·썸네일·이용권은 제공되지 않아 주소 연결과 구매를 비활성화했습니다. 자체 CSS로 만든 임시 시즌 아트가 카드에 표시됩니다. 임의 주소·가격·혜택은 넣지 않았습니다. 제공 후 코드 설정만 채우면 기존 UI에서 동작합니다.

## 구조

- `src/catalog.ts`: 고정 제목·게임·상품 설정
- `src/core.ts`: 데이터 모델, 보상·장부·순위·취소·이용권·백업 검증
- `src/storage.ts`: 저장 잠금·버전 충돌·최근 정상본·파일 다운로드
- `src/main.tsx`: 대시보드·관리 패널·결과 입력·공개 연출
- `src/style.css`: 반응형 디자인·모션 감소
- `src/core.test.ts`: 핵심 규칙과 저장 실패 단위 테스트

백업 형식은 version 1입니다. 이후 스키마 버전 변경 시 validateBackup 진입 전에 명시적 마이그레이션 함수를 추가해야 합니다. 미지원 버전은 원본을 보존하고 거부합니다.

## 검증 범위

핵심 테스트: 참가·추가·팀·순위·직접 배정, 미참가, 조정, 공동 순위, 여러 경기 합산, 중복 지급, 취소·재지급, 잔액 부족 취소 차단, 상품 구매·환불·중복 차단, 백업 구조·버전·참조·금액·중복 검사, 저장·로드·탭 충돌·저장 실패 원본 보존.

실제 사용자 정보 대신 가상 학생으로 UI를 검증합니다. 실제 외부 게임 URL과 운영 상품은 미제공 상태이므로 해당 게임 접속 및 실제 상품 운영 검증은 정보 등록 후 필요합니다. 장치별 실제 프로젝터·음향·전체 화면과 물리적 저장 공간 부족은 추가 현장 확인이 필요합니다.

백업 JSON에는 학생 이름과 거래 사유가 포함되므로 안전하게 보관하세요. 브라우저 저장은 암호화된 계정 보안이 아닙니다. 공개 화면에서 교사 패널을 열면 투사됩니다.


## GitHub에 업로드하기

1. ZIP 압축을 해제합니다.
2. GitHub에서 새 저장소를 만들고 **Add file → Upload files**를 엽니다.
3. 압축을 푼 내용물 전체(특히 `src` 폴더, `package.json`, `package-lock.json`, `index.html`, `vite.config.ts`, `tsconfig.json`, `.gitignore`)를 업로드하고 커밋합니다. ZIP 파일 자체만 올리면 소스가 펼쳐지지 않습니다.
4. 로컬에서 실행하려면 해당 폴더에서 `npm ci` 후 `npm run dev`를 실행합니다. Node.js 22 LTS 이상을 사용하세요.
5. Vercel로 배포한다면 저장소를 연결하고 Framework: **Vite**, Build Command: **npm run build**, Output Directory: **dist**로 설정합니다. 이 프로젝트에는 API 키나 환경변수가 필요하지 않습니다.

GitHub에 소스만 올려서는 사이트가 실행되지 않습니다. Vercel 등 정적 호스팅 또는 별도 GitHub Pages 빌드 배포를 설정해야 합니다. `vite.config.ts`는 상대 경로를 사용하므로 GitHub Pages의 저장소 하위 경로 배포에도 대응합니다. GitHub Pages 자동 배포 워크플로는 포함하지 않았습니다.

이 배포용 소스에는 ChatGPT Sites 전용 설정이나 로그인 기능이 없습니다. 일반 정적 호스팅에 올리면 앱 자체 로그인 없이 이용할 수 있습니다. 기존 사이트와 주소가 달라지면 브라우저 기록은 자동으로 이전되지 않으므로 기존 사이트에서 백업한 뒤 새 주소에서 복구해 주세요.

학생 실제 명단·가넷 기록·인증 정보·node_modules·빌드 결과·기존 Git 기록은 ZIP에 포함하지 않았습니다. 테스트 코드의 이름은 가상 데이터입니다.
