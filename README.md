# 지니어스 게임

초등 학급용 게임 로비와 시즌 가넷 장부입니다. GitHub `kssaembo/genius`의 `2117e495cdc8b8275ac8960a3e4ad9398db84be0`를 기준으로 수정했습니다.

## GitHub에 적용

1. 기존 서비스에서 교사 메뉴 → 백업·복구로 백업합니다.
2. 압축을 풀고 내용물을 기존 저장소 루트에 덮어씁니다. ZIP 파일 자체를 업로드하지 않습니다.
3. 커밋 후 Vercel 배포가 끝나면 새로고침합니다.

Vercel: Framework `Vite`, Build `npm run build`, Output `dist`. 환경변수는 필요 없습니다. GitHub에 직접 반영하거나 운영 사이트를 배포하지 않은 전달용 소스입니다.

## 실행과 검증

```sh
npm ci
npm test
npm run build
npm run dev
```

Chrome/Edge 최신 버전을 권장합니다. 저장 기능은 HTTPS 또는 localhost에서 동작하며 Web Locks가 필요합니다. 현재 HTTP 미리보기에서는 UUID·Web Locks가 제공되지 않아 시즌 생성 이후의 브라우저 조작은 검증하지 못했습니다. 메인 화면을 육안 점검했고 계산·저장·초기화·이용권·마이그레이션·명단 테스트 19개와 TypeScript/Vite 빌드를 통과했습니다.

## 이번 수정

- 사이트 이름: 지니어스 게임.
- 제목·게임명·하단 탭: 마루 부리 / 본문·버튼·학생명·숫자: Pretendard.
- 메인 인사말·설명·우측 상위 순위·슬라이드 표시 삭제.
- 게임 선택과 최종 순위는 페이지 이동 없이 세로 스크롤.
- 학생 목록 복사와 게임 관리 버튼 강조, 하단 탭에 금속성 이중 금빛 테두리 적용.
- 교사 메뉴·설정·게임 소개·결과 입력 글자와 터치 영역 확대.
- 팀별 보상·팀 선택·팀 추가 제거. 이전 팀 방식은 학생별 직접 지급으로 변환하며 지급 총액과 기존 장부를 보존.
- 결과 입력의 조정 사유 제거. 수동 조정 숫자 옆 가넷 −/+ 버튼은 입력값을 1씩 바꾸고 회차 지급 시 반영.
- 학생 가넷 장부는 거래 유형·사유 선택 없이 숫자를 입력하고 '가넷 반영'. 가넷 −/+ 버튼은 클릭 즉시 1가넷씩 장부에 반영.
- 수동 가넷은 보유량과 누적 획득·순위에 반영. 차감 시 누적은 0까지, 보유량은 음수가 되지 않도록 제한. 기존 시작 지급은 순위에서 제외.
- 교사 메뉴에 시즌 초기화 추가. 확인 후 명단·게임 순서·보상·이용권 설정을 유지하며 결과·거래·구매 이력을 초기화. 시작 가넷으로 복원. 최근 정상 저장본도 남음.

## 이용권

역할: 힌트 등 교사가 적용할 혜택을 가넷으로 구입했는지 기록합니다. 외부 게임에 자동으로 적용되지는 않습니다.

등록: 게임 카드 '게임 소개' → '이용권 설정'을 펼침 → 이름·내용·가격 입력 → 저장.
구매: 같은 화면에서 학생을 선택하고 구매. 사용·환불: '이용권 기록' 탭.
가격을 바꿔도 기존 구매의 가격·내용은 유지합니다. 이용권 구매·환불은 보유 가넷에만 반영되며 순위를 바꾸지 않습니다. 설정은 회차별이며 백업에 포함됩니다.

## 저장과 복구

학생과 장부는 현재 브라우저 LocalStorage에 저장됩니다. 동일 도메인·브라우저의 기존 데이터를 계속 불러옵니다. 다른 PC는 백업 JSON으로 옮깁니다. 백업에는 학생 정보가 포함됩니다.

## 폰트와 게임 주소

폰트는 공식 배포 웹폰트 CSS를 사용합니다. 별도 폰트 파일은 포함하지 않습니다. 인터넷 또는 CDN 접근이 제한되면 시스템 폰트로 표시됩니다.

- 마루 부리: https://hangeul.naver.com/font
- Pretendard: https://github.com/orioncactus/pretendard

게임별 외부 URL은 기존대로 `src/catalog.ts`의 `url`에 입력합니다. 아직 제공되지 않은 주소는 비활성 상태입니다.
